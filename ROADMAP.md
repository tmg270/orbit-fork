# GrokLink roadmap

A direction, not a promise of dates. Shipped work lives in What's New and CHANGELOG.md.

## Now

- **SuperGrok sign-in**: confirm it works for every SuperGrok plan, with clear messages when xAI
  refuses a plan or a model.
- **Android Auto**: ask Grok from Android Auto's media apps and hear the answer in the car.
  Experimental; needs Android Auto developer mode.
- **Smart Vault**: Vault search and suggestions written by Grok, tappable sources in Ask Vault
  answers, and richer retrieval across saved documents.

## Later

- Signed releases published as GitHub Releases.
- Calendar awareness, more Routine branch points and conditions, stronger Custom Commands, deeper
  Android actions.

## Exploring

- A smoother hands-free Android Auto flow, if Android Auto allows it for sideloaded apps.
- Proactive screen intelligence that stays transparent and controllable.

The upstream Orbit Assistant roadmap is at https://github.com/lpnovi/Orbit-Assistant.
